# Glossary and abbreviations

| Term | Meaning |
|---|---|
| AIR / OIR | Asset / Organisational Information Requirements |
| BAG / BRK / BGT | Dutch base registers: Addresses and Buildings / Cadastre / Large-scale Topography |
| Bbl | *Besluit bouwwerken leefomgeving* (national building decree under the Environment and Planning Act) |
| BCF | BIM Collaboration Format: exchange of issues |
| bSDD | buildingSMART Data Dictionary |
| CDE | Common Data Environment |
| DSO | *Digitaal Stelsel Omgevingswet* (national digital system; the *Omgevingsloket* is its portal) |
| EIR / IPR | Exchange Information Requirements / Information Production Requirements (revised ISO 19650) |
| GEMMA | *Gemeentelijke Model Architectuur* (municipal reference architecture of VNG) |
| IDM | Information Delivery Manual (ISO 29481) |
| IDS | Information Delivery Specification (buildingSMART) |
| IFC | Industry Foundation Classes (ISO 16739-1) |
| ILS | *Informatieleveringsspecificatie* (information delivery specification) |
| LOIN | Level of Information Need (ISO 7817-1) |
| MPG | *Milieuprestatie gebouwen* (environmental performance of buildings) |
| NAP | *Normaal Amsterdams Peil* (Dutch vertical datum) |
| OPA / BOPA | (*Buitenplanse*) *omgevingsplanactiviteit* (zoning plan activity, or activity outside the zoning plan) |
| Qto | Quantity set in IFC |
| ReSpec | Tool for publishing specifications as a web page |
| SPARQL | Query language for RDF data |
| STB 2025 | *Standaard Taakbeschrijving* (standard task description, BNA/NL Ingenieurs) |
| TBA | *Technische bouwactiviteit* (technical building activity) |
| VNG | *Vereniging van Nederlandse Gemeenten* (Association of Netherlands Municipalities) |
| VTH | *Vergunningverlening, toezicht en handhaving* (permitting, supervision and enforcement) |
