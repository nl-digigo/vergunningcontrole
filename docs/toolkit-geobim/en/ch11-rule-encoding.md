# Rule encoding (layer 4) {#regelcodering}

<p class="leesniveau technisch">Technical</p>

This chapter describes how a check is recorded in machine-readable form: the formal representation of a rule that software can read and execute. It is layer 4 of the [[[#regellagen]]].

A fully worked example for rule #2 (maximum building height), with SHACL and SPARQL examples, is in [[[#voorbeeld-regel-2]]].

<div class="issue" title="Chapter under construction">

For each check, the following still needs to be worked out:

- a **description** of the encoded rule;
- the **encoding** itself, for example in SHACL and/or SPARQL;
- the **output**: which result the check produces and in what form.
