# Rule interpretation per check {#regelinterpretatie}

<p class="leesniveau tactisch">Tactical</p>

This chapter describes, for each of the seventeen checks: the check itself, the current working method, the regulatory source, the current assessment time and remarks. It covers layers 0 and 1 of the [[[#regellagen]]]. The content is the result of physical sessions with participating municipalities on 7 April and 8 June 2026 in Zoetermeer.
