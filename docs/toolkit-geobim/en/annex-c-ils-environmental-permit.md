# ILS for the environmental permit — specifications {#ils-omgevingsvergunning}

<p class="leesniveau tactisch">Tactical</p>

This annex contains the 42 machine-readable submission requirements for modelling spaces in an environmental permit application, expressed as buildingSMART IDS [[IDS]], with an overview per check and per specification. The same specifications are also maintained in the separate ILS Omgevingsvergunning document [[ILS-OMGEVINGSVERGUNNING]], which has its own English version.
