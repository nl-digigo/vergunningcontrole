# Bijdragen

1. **Vraag of fout?** Maak een issue aan met een van de sjablonen.
2. **Tekstvoorstel?** Maak een branch, pas het Markdown-bestand in `hoofdstukken/` aan en open een pull request. Minimaal één andere redacteur reviewt.
3. **IDS-wijziging?** Pas het bestand in `ids/` aan, verhoog `ids:info/version` en werk `data/specificaties_checks.csv` bij als de checks veranderen.
4. Inhoudelijke wijzigingen en beslispunten gaan langs het BM13-projectoverleg.

Werkwijze: GitHub Desktop plus Visual Studio Code (of CodeEdit op Mac). Commit met een korte, beschrijvende boodschap.

Geen GitHub-account? Mail je reactie naar de redactie; die zet hem om in een issue.
