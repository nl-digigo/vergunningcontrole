# Terms and definitions {#begrippen}

<p class="leesniveau tactisch">Tactical</p>

This chapter contains the terms used throughout the toolkit. A term defined here is automatically underlined elsewhere in the document and linked to this definition.

<div class="issue" title="Glossary v0">

This is a first draft. The choice of terms (which terms we do and do not define) still has to be agreed, and the list will be aligned with digiGO's existing glossaries.

</div>

<dl>
  <dt><dfn>BIM</dfn></dt>
  <dd>Building Information Model: a digital model of a building in which objects, such as walls, spaces and storeys, are recorded together with their properties.</dd>
  <dt><dfn>IFC</dfn></dt>
  <dd>Industry Foundation Classes: the open, international standard (ISO 16739) for exchanging BIM models between software packages.</dd>
  <dt><dfn>IDS</dfn></dt>
  <dd>Information Delivery Specification: a buildingSMART standard for recording information requirements for an IFC model in machine-readable form, so that software can check whether a model contains that information.</dd>
  <dt><dfn>ILS</dfn></dt>
  <dd>Informatieleveringsspecificatie (information delivery specification): agreements on which information must be supplied in which form, here for an environmental permit application with a BIM model.</dd>
  <dt><dfn>GeoBIM</dfn></dt>
  <dd>Combining BIM models with geo-information, such as cadastral parcels, environment plan rules and key registers, so that a building can be assessed in its surroundings.</dd>
  <dt><dfn>Check</dfn></dt>
  <dd>A single checkable rule from the environment plan or the Bbl, such as <em>maximum building height</em>, as worked out in this toolkit.</dd>
  <dt><dfn>Bbl</dfn></dt>
  <dd>Besluit bouwwerken leefomgeving (Buildings (Living Environment) Decree): the national rules under the Omgevingswet for building, use and fire safety, among other things.</dd>
  <dt><dfn>Environment plan</dfn></dt>
  <dd>Omgevingsplan: the municipal plan under the Omgevingswet containing the rules on the physical living environment within a municipality.</dd>
</dl>
